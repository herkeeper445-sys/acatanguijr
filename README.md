# Ananias Jr. D. Catangui — VA Portfolio

Custom Next.js portfolio for Ananias Jr. D. Catangui, an entry-level General Administrative Virtual Assistant.

## Primary design reference

- Live reference: https://sample-nextjs-portfolio.vercel.app/?utm_source=chatgpt.com
- Public source reference: https://github.com/iammiracle01/sample-next-js-portfolio
- The reference is used for visual direction only: dark futuristic styling, animated spotlight hero, floating navigation, bento/grid sections, project presentation, experience/approach flow, and split contact layout.
- All personal information, project descriptions, VA practice samples, and contact details in this repository are customized for Ananias.

## Included

- Animated spotlight hero
- Profile photo with orbiting particle dots behind it
- Floating navigation
- Bento-style About section
- Interactive previews for email, calendar, meeting minutes, research, travel planning, Drive organization, customer support, onboarding SOP, task management, AI-assisted admin work, and spreadsheet/dashboard practice
- Canva practice cards
- APEX personal learning project
- n8n workflow automation practice
- Transferable experience section
- Work approach section
- Gmail, LinkedIn, WhatsApp, Telegram, phone, and location
- Contact form that opens the visitor's email app
- Printable `/resume` page

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Important labeling

All self-created practice samples are clearly labeled as practice. Fictional names/data are not represented as paid client work.
